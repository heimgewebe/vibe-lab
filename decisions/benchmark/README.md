# Decisions / Benchmark — Stub-Namespace

Dieser Namespace enthält aktuell nur dieses README als Stub-Marker; fachliche Artefakte liegen hier noch nicht.

`decisions/benchmark/` ist Teil der **typisierten Decision-Namespaces**
(`process/`, `system/`, `export/`, `policy/`, `benchmark/`), die im Repo-Plan
als Phase-C-Verstärker angelegt sind
(`docs/foundations/repo-plan.md` → „Typisierte Decision Artifacts").

**Zweck:** Hier landen Decision Artifacts, die sich auf Benchmark-Definitionen
oder -Vergleichsläufe beziehen — z. B. Versionsentscheide für eine
Benchmark-Challenge, Festlegung neuer Bewertungs-Achsen oder
Stop-Kriterien für Vergleichsstudien.

Bislang ist keine solche Entscheidung getroffen worden. Benchmarks selbst
liegen unter [`benchmarks/`](../../benchmarks/) und brauchen für ihre
laufende Pflege kein Decision-Artefakt.

**Schema:** Decision-Artifacts ohne `decisions/system/`-Bezug haben aktuell
**keinen** Pflicht-Contract. Erst beim ersten realen Eintrag wird entschieden,
ob ein eigener Schema-Strang sinnvoll ist.
