# Model-Lab Boundary Notes

The canonical method document defines the current Run-004 boundaries. The prompt intervention is one complete bundle, so no individual wording feature is isolated. Historical source snapshots are checked against their declared repository objects during every validation. The design remains unexecuted and does not establish assessment readiness or a condition effect.

Only language, permissions, composition order, benchmark, and shared condition are constant across arms. Specification ordering, completeness rules, examples, length, structure, directive strength, motivational framing, and required sections belong to the complete intervention bundle.

For each frozen source, validation reads the historical object identified by `source_commit_sha:source_path` and requires byte equality with the snapshot. Unavailable history, a missing historical path, or different bytes stops validation; CI therefore needs full repository history.
