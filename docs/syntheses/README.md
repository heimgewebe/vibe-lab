# Syntheses — Stub-Namespace

Dieser Namespace enthält aktuell nur dieses README als Stub-Marker; fachliche Artefakte liegen hier noch nicht.

**Stub-Status:** `dormant`.

- Grund: Eine Synthese ohne mehrere belastbare Quellen wäre Verdichtung vor Evidenz.
- Reaktivierung: Wenn mehrere Experimente, Evaluationen oder Decisions eine übergreifende Aussage tragen, darf genau ein konkretes Synthese-Artefakt als `minimal-seed` entstehen.
- Grenze: `dormant` bedeutet nicht `queued`; aus diesem Stub folgt keine Pflicht, den Namespace künstlich zu befüllen.

`docs/syntheses/` ist im Zielbaum als Ablage für **verdichtete Erkenntnisse**
vorgesehen (`docs/foundations/repo-plan.md` → Zielstruktur, Abschnitt `docs/syntheses/`).

Eine Synthese entsteht typischerweise, wenn mehrere Experimente,
Evaluationen oder Decisions zu einer übergeordneten Aussage führen, die
weder als einzelnes Experiment-Ergebnis noch als Catalog-Eintrag gut
abbildbar ist.

**Verwandte aktive Pfade:**

- `docs/evaluations/` — laufende Auswertungen einzelner Befunde
- `catalog/` — adoptierte Praktiken als Endprodukt
- `docs/concepts/` — vorgelagerte Denkmodelle
