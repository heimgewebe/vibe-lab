=== What Would Constitute Independence ===
For an auditor to be genuinely independent, ALL of the following must be true:

1. DIFFERENT SESSION: The auditor runs in a session that did not execute the run.
   Evidence required: different session ID, different invocation log, or different
   timestamp chain that cannot be the same agent continuing work.

2. DIFFERENT AGENT OR HUMAN: Either:
   (a) A different AI agent (e.g., a Copilot agent reviewing a PR opened by this
       session), OR
   (b) A human reviewer who reads the run artifacts and produces a written review.

3. TRACEABLE OUTPUT: The auditor produces output that can be located:
   - A GitHub PR review comment (with reviewer identity and timestamp), OR
   - An auditor-output.yml produced by the separate session/agent/human, OR
   - A written review document with external attribution.

4. NO REPAIR: The auditor must not modify any other artifacts. The only permitted action is
   replacing auditor-output.yml with the externally produced audit output. All other run
   artifacts remain read-only. The auditor reads evidence and produces verdicts only.
