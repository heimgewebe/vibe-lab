# Outcome-Evidence-Replication-Series — Failure Modes

## When does this approach NOT work?

- If the series never reaches four comparable runs, the gate stays underpowered.
- If all review is only partial independence, no full independence claim is warranted.
- If the negative control does not hold `CLAIM_NOT_PROVEN`, the series is not safe for upgrade decisions.
- If task classes are not diverse, the series remains too narrow to support the intended claim.

## Known False Assumptions

- Different sessions alone are enough for independence.
- A single strong run can substitute for run-over-run evidence.
- Planning artifacts can be treated as execution evidence.

## Limits of the Evidence

- Sample size: none yet; the series is planned only.
- Context dependence: later runs may still be specific to this repository and model mix.
- Self-selection: future run choices may overfit the desired gate outcome.

## Misuse Risk

If this scaffold is treated like evidence, it can create a false sense of readiness and lead to premature outcome upgrades.
