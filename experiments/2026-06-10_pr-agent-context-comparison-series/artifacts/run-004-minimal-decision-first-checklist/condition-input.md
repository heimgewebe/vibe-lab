# Condition Input — Run 004: Minimal Decision-First Checklist

## Condition

`minimal-decision-first-checklist`

## Checklist

1. State the target.
2. State what is already evidenced.
3. State what is missing.
4. Name at most three hypotheses.
5. Name two to five checks.
6. Define the stop criterion.
7. Only then give a patch, review verdict, or agent instruction.

## Purpose

This is the low-ceremony counter-condition. It tests whether a small thinking
filter captures most of the benefit without full Vibe-Lab run discipline.

## Boundary

No full Vibe-Lab handoff and no Lenskit/repoLens context unless explicitly part
of the source task.
