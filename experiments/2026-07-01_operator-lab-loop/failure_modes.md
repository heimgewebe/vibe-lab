# failure_modes.md — Operator Lab Loop

## Erwartete Fehlmodi

- Der Loop wird zur Pflichtbuerokratie und verlangsamt triviale Arbeiten.
- Ein einzelner erfolgreicher Run wird als Adoption-Beweis fehlgedeutet.
- Bureau wird zu frueh beruehrt und erzeugt Aufgaben, bevor Vibe-Lab Evidence hat.
- Steuerboard-Signale werden als Freigabe missverstanden.
- Evidence besteht nur aus Selbstbericht.

## Gegenmittel

- Opt-in-Ausloeser statt globaler Pflicht.
- Explizite `does_not_establish`-Liste je Run Card.
- Bureau-Bruecke erst nach wiederholter Reibung oder klarer Folgearbeit.
- Steuerboard als Nutzungsprobe dokumentieren, nicht als Gate.
- PASS-Claims nur mit repo-lokaler oder stabil verifizierter Evidence.
