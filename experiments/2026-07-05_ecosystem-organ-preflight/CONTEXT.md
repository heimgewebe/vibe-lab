# CONTEXT.md — Ecosystem Organ Preflight

## Ausgangslage

Das heimgewebe-Ökosystem nutzt mehrere Organe mit unterschiedlichen Rollen: Vibe-Lab für Experimente, GitHub/CI für PR-Wahrheit, rLens/Bundle-Dumps für Quellkontext, Grabowski für operative Repo-Arbeit, Bureau für Priorisierung und Cabinet für Wissenskontext.

Das Experiment prüft, ob eine kurze Organ- und Wahrheitsquellenkarte vor größeren Aufgaben bessere Orientierung erzeugt.

## Umgebung

- **Tools:** ChatGPT, GitHub connector, Vibe-Lab
- **Sprache:** Markdown / YAML
- **Projekttyp:** Multi-Repo-Ökosystem mit PR-, CI-, Agenten- und Dokumentationsarbeit

## Relevante Vorarbeiten

- Vibe-Lab nutzt Experimente als Hypothesen- und Evidenzfläche.
- Der aktuelle Slice ist nur entworfen, nicht adoptiert.
- Spätere Claims brauchen Auswertung über mehrere reale Aufgaben.

## Einschränkungen

- Noch keine codierte Baseline.
- Noch keine Treatment-Reihe.
- Keine produktive Schaltung weiterer Organe.
