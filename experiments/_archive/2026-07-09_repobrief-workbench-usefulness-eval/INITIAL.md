# Initial Setup

## Initial operator task

```text
Bureau task RPU-V1-T012:
Measure whether RepoBrief/Agent Workbench surfaces actually improve agent code
work versus no-rLens, reading-pack, context-pack, full-dump and trace-gated
conditions.
```

## Baseline expectation

Without a structured evaluation, later claims such as "RepoBrief helps agents"
would likely rely on anecdotal impressions, passing tests, or self-authored
checks. This experiment makes that insufficient by requiring condition labels,
comparable task classes, explicit metrics, miss taxonomy and independent
observations.

## Starting status

The experiment starts in `designed` state. It has no executed run series and no
promotion decision.
