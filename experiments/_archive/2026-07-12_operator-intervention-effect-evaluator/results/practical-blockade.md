# Practical blockade

## Dialectical finding

The implementation is internally deterministic and evidence-bound. That supports retaining the utilities as generic Vibe-Lab review tooling.

The registered usefulness experiment is nevertheless non-executable: its treatment needs the evaluator report before deciding, while the report needs both already decided and independently scored conditions. Technical correctness of the calculator therefore does not establish practical evaluability of the registered intervention.

## Verified sequence

1. Registration freezes `manual_review` versus `evaluator_assisted_review`.
2. The treatment description requires the deterministic effect report in addition to the same underlying evidence.
3. The method seals and scores both decisions before capture.
4. `evaluate_effect.py` consumes those captured scores to produce the effect report.
5. The report is consequently downstream of the treatment decision it was supposed to inform.

## Why no pilots were manufactured

A second pre-decision reporter would be a new intervention. Retrofitted old cases would not be prospective. Synthetic read comparisons would not be naturally occurring operator decisions. Repeating productive mutations would add avoidable risk. Each path violates an explicit experiment or salvage constraint.

## Disposition

- Reject the registered three-pilot salvage experiment and remove it from the active registry.
- Do not move the evaluator into Heimlern and do not call it a proven capability.
- Retain the generic capture/evaluation utilities in Vibe-Lab only as unpromoted review tooling.
- Do not add Chronik events, a service, dashboard, Plexer integration, routing weights or policy mutation.
- When Bureau is safe to mutate, record PR #313 as implementation evidence, close the prior usefulness proof as insufficient evidence, keep T004 unpromoted and record this archive decision without creating a parallel initiative.

## Non-claims

This blockade does not prove that manual review is better, that deterministic summaries are useless in every context, or that Heimlern repository archival has already occurred. It proves only that this frozen experiment cannot honestly produce the requested causal comparison with the merged implementation.
