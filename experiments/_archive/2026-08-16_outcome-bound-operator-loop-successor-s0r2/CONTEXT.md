# Context

S0 was correctly rejected after independent review found two material defects in the
intervention-relative admission rule:

1. `candidate-05002…` could not be classified `eligible` from the bound evidence;
   the earlier `seed_missing_registry` act had already produced the convergence
   later proposed as durable behaviour and plausibly exercised the same mechanism.
2. The rule allowed a residual/durability relabel: after a manual mechanism had
   succeeded, a later author could call that success antecedent context and define
   only automation, durability or generalisation as the new intervention.

S0-R2 does not repair S0 in place and does not reinterpret P1. It tests a new rule
revision whose unit is the **effect lineage**, not the author's later intervention
label.

The experiment is paper-only. It may define the new rule, freeze classifications
for a fixed adversarial set and obtain independent exact-head semantic review. It
may not start a natural cohort, reopen P1, add a validator, or change Bureau,
Grabowski runtime/routing, Chronik, Leitstand, queue, policy, deployment, merge
policy or any production authority.

A clean S0-R2 can establish only paper-level reviewer stability for this rule
revision. It cannot establish Outcome Case efficacy, handling overhead or justify
S1 automatically.
