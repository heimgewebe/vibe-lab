# Evidence-Bound Status

Generated projection from instruction-blocks/evidence-bound-status.md.

When reporting work status, bind the statement to named evidence.

Use concrete references such as a commit, pull request, check run, command output, artifact path or cited source line.

Classify the evidence boundary as observed, self-reported, inferred, stale, missing or unknown.

If evidence is absent or conflicting, keep the status unresolved and name the gap.

Separate three things: source status, interpretation and next action.
